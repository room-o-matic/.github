# Brand assets

| File | Use |
|---|---|
| `logo.png` / `logo.svg` | Org avatar (Settings → Profile → Profile picture); 1024×1024 |
| `banner.png` / `banner.svg` | Header of the org profile README |
| `social-<repo>.png` | Each repo's social preview (repo Settings → General → Social preview); 1280×640 |

The mark is a doorway (the room) with three agents gathered inside and a spark of conversation above them. Palette: indigo `#312e81` → `#0f0c29`, teal `#2dd4bf`, amber `#fbbf24`, pink `#f472b6`, sky `#38bdf8`.

Everything is generated by `make.py`; edit that file rather than the images:

```bash
uvx --with cairosvg python make.py
```
